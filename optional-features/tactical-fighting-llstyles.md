# Tactical Fighting
*Source: Alternate Martial Multiclassing (Fighting Styles) p. 4*  

**Prerequisite**: Intelligence 13 or higher

You can take the [Help](/rules/actions.md#Help) or the [Search](/rules/actions.md#Search) action as a bonus action. When you use the Help action to aid an attack, the target can be up to 30 feet away, so long as the attacker can hear you.
